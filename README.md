# Employee Attrition Analysis | Power BI Project

## 📌 Project Overview

This project analyzes employee attrition using Microsoft Power BI. It explores workforce data to understand employee turnover patterns across job roles, age groups, education levels, salary hikes, experience, and job satisfaction.

## 🎯 Project Objectives

- Measure overall employee attrition.
- Identify job roles and employee groups with higher attrition.
- Analyze attrition patterns across age and education groups.
- Explore salary hike, work experience, and job satisfaction.
- Present HR insights through an interactive dashboard.

## 🛠️ Technologies Used

- **Microsoft Power BI:** Dashboard development and visualization
- **Microsoft Excel:** Data preparation and inspection
- **SQL:** Data querying, if used in the project
- **Python:** Data analysis, if used in the project

## 📊 Dashboard Highlights

- Total Employees
- Total Attrition
- Attrition Percentage
- Average Age
- Average Income
- Education-wise Attrition
- Job-wise Attrition
- Attrition by Age Group
- Attrition by Years of Experience
- Attrition by Salary Hike
- Attrition by Job Satisfaction

## 💡 Business Insights

The dashboard helps explore employee turnover patterns and identify workforce segments that may need further investigation. These insights can support HR teams in developing data-informed retention strategies.
